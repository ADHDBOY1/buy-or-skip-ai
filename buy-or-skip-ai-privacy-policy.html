Privacy Policy for Buy or Skip AI

Effective date: June 29, 2026

Buy or Skip AI has no user accounts, advertising, analytics, tracking, or developer-operated backend. Product information is sent to Google Gemini only when the user requests an analysis.

1. What the extension does

Buy or Skip AI helps users evaluate products shown on online shopping pages. It extracts relevant product details and, after the user clicks an analysis button, sends those details to the Google Gemini API to generate a BUY, WAIT, SKIP, or NOT ENOUGH INFO verdict.

2. Information handled by the extension

The extension may handle:

  • Product-page information, including the page URL, domain, title, price, currency, brand, rating, review count, product description, structured product metadata, product image URL, extraction confidence, and a limited snippet of visible page text.
  • Product details entered manually by the user.
  • User-provided Google Gemini API keys.
  • User preferences, including analysis tone and related settings.
  • Local analysis history, including product details, page URL, analysis result, and analysis date.

3. How information is used

Page and manually entered product information is used only to display the detected product to the user, generate the requested AI shopping analysis, provide research links, and maintain the optional local analysis history.

Gemini API keys are used only to authenticate requests that the user initiates to the Google Gemini API.

4. Data sharing and external processing

When the user clicks Analyze Product or Analyze Manual Product, relevant product information and the user's Gemini API key are sent directly from the extension to the Google Gemini API over HTTPS. Google processes that request according to the terms and privacy practices applicable to the user's Google Gemini API access.

The developer does not operate a server that receives the user's API key, product-page data, analysis history, or Gemini response. The extension does not sell user data and does not share data for advertising, profiling, creditworthiness, or unrelated purposes.

5. Local storage and retention

Gemini API keys, preferences, and analysis history are stored locally using Chrome extension storage on the user's device. They remain there until the user removes them through the extension, clears extension data, or uninstalls the extension.

The extension allows users to clear saved API keys and analysis history. Data processed by Google Gemini is subject to Google's applicable retention practices and terms.

6. Security

Requests to the Google Gemini API use HTTPS. API keys are stored in local Chrome extension storage and are not intentionally exposed to websites visited by the user. No method of local storage or electronic transmission can be guaranteed to be completely secure.

7. Chrome Web Store Limited Use disclosure

Buy or Skip AI's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the extension's single user-facing purpose. It is not sold, used for personalized advertising, or transferred for unrelated purposes. Humans do not read user data except where the user gives specific consent for support, where required for security, where required by law, or where otherwise allowed by the Chrome Web Store User Data Policy.

8. Children's privacy

Buy or Skip AI is not directed to children under 13 and does not knowingly collect children's personal information.

9. Changes to this policy

This policy may be updated when the extension's functionality or data practices change. The effective date at the top of this page will be updated when changes are published.
